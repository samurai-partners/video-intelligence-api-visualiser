# Video QA Review — 仕様書

## プロジェクト概要

動画をAI（Google Video Intelligence API + Gemini 2.0 Flash）で解析し、ターゲット視聴者に不適切な箇所を自動検出するWebアプリ。

### 技術スタック
- **フレームワーク**: Next.js 16 (App Router) + React 19 + TypeScript 5.9
- **スタイル**: Tailwind CSS 4 + PostCSS
- **状態管理**: Zustand 5
- **AI**: Video Intelligence API (9機能), Gemini 2.0 Flash (マルチモーダル)
- **PDF**: @react-pdf/renderer

## 音声文字起こしフロー（現在の実装）

### データの流れ
```
1. 動画アップロード
   └→ FormData → videoBuffer (Buffer)

2. Video Intelligence API (videoIntelligence.ts)
   ├→ analyzeVideo(videoBuffer, language)  ← language引数で言語コード動的化済み
   ├→ LANG_TO_BCP47マッピング: ja→ja-JP, en→en-US, zh→zh-CN, ko→ko-KR 等13言語
   └→ VIRawResult.speechTranscriptions[]: { transcript, words[] }

3. シーン分割 (segmentIntoScenes)
   └→ 各 Scene.viData.speechTranscription: SpeechWord[] (シーン時間範囲でフィルタ)

4. Gemini動画アップロード (uploadVideoToGemini)
   ├→ Blob変換 → genAI.files.upload()
   ├→ PROCESSING状態をポーリング（2秒間隔）
   └→ videoFileUri (ACTIVE状態で返却)

5. Gemini多言語文字起こし (transcribeWithGemini)
   ├→ 英語プロンプト（多言語対応）
   ├→ 自動言語検出 (detectedLanguage: ISO 639-1コード)
   ├→ 原文: words[] + fullTranscript
   ├→ 日本語翻訳: translatedWords[] + translatedTranscript
   └→ GeminiTranscriptionResult型で返却

6. シーンへの分配 (applyGeminiTranscription)
   └→ 各 Scene.geminiTranscription: {
        words, fullTranscript,
        detectedLanguage,
        translatedTranscript, translatedWords
      }

7. UI表示 (SceneDetailPanel.tsx)
   ├→ 言語バッジ: 検出言語をインジゴ色で表示
   ├→ 翻訳ON/OFFトグル: 日本語翻訳の表示切替
   ├→ Gemini音声要約: 紫色カード
   ├→ 翻訳全文: 緑色カード（翻訳ON時）
   ├→ ワードレベル: 原文 + インライン翻訳（文ごと）
   ├→ アクティブ文: 青枠 + 自動スクロール
   ├→ アクティブワード: 赤下線（原文）/ 緑下線（翻訳）
   └→ クリック: 該当ワードの startTimeSeconds にシーク
```

### Phase 2（3週目）: 文字起こしと動画のマッチング精度向上

**目的**: 文字起こし結果と動画再生のリアルタイム同期を改善する

#### 2-1. シーン単位Gemini文字起こし
**ファイル**: `src/lib/gemini.ts`, `src/app/api/analyze/route.ts`

現状:
```
1. 動画全体をGeminiに渡して一括文字起こし
2. ワードのstartSecondsでシーンに分配 (applyGeminiTranscription)
```

変更後:
```
1. シーンごとに「動画の X秒〜Y秒 の音声を文字起こし」とプロンプト
2. 各シーンの結果をそのまま Scene.geminiTranscription に格納
```

メリット:
- タイムスタンプの精度が上がる（シーン範囲内の相対位置）
- 長い動画でもJSON出力が切れない
- シーンごとにSSEログで進捗表示できる

## 型定義（主要）

### Scene (scene.ts)
```typescript
interface Scene {
  index: number;
  startTimeSeconds: number;
  endTimeSeconds: number;
  durationSeconds: number;
  viData: {
    detectedText: DetectedText[];
    speechTranscription: SpeechWord[];
    fullTranscript: string;
    labels: SceneLabel[];
    explicitContent: { maxLikelihood: string; frames: ExplicitContentFrame[] };
    objects: TrackedObject[];
    persons: PersonDetection[];
    faces: FaceDetection[];
    logos: LogoRecognition[];
  };
  geminiTranscription?: GeminiTranscription;
  geminiAnalysis?: {
    summary: string;
    issues: SceneIssue[];
    overallRisk: "low" | "medium" | "high";
    detectedTextSummary?: string;
    speechSummary?: string;
  };
}
```

### SpeechWord (scene.ts)
```typescript
interface SpeechWord {
  word: string;              // 形態素/単語
  startTimeSeconds: number;  // 開始秒
  endTimeSeconds: number;    // 終了秒
  confidence: number;        // 信頼度 (0-1)
}
```

### GeminiTranscription (scene.ts)
```typescript
interface GeminiTranscription {
  words: SpeechWord[];
  fullTranscript: string;
  detectedLanguage?: string;         // ISO 639-1 (e.g. "en", "ar")
  translatedTranscript?: string;     // 日本語翻訳全文
  translatedWords?: SpeechWord[];    // 日本語翻訳ワード（元のタイムスタンプを維持）
}
```

### GeminiTranscriptionResult (gemini.ts)
```typescript
interface GeminiTranscriptionResult {
  words: Array<{ word: string; startSeconds: number; endSeconds: number }>;
  fullTranscript: string;
  detectedLanguage: string;
  translatedTranscript: string;
  translatedWords: Array<{ word: string; startSeconds: number; endSeconds: number }>;
}
```

### ProjectConfig (project.ts)
```typescript
interface ProjectConfig {
  targetAudience: TargetAudience;
  targetAudienceCustom?: string;
  videoPurpose: string;
  language: string;          // ISO 639-1コード or "auto"
  additionalRules?: string;
}
```

## API フロー図

```
[クライアント]
    │
    ├─ POST /api/analyze (FormData: video + config + duration + mock)
    │   │
    │   ├─ SSE: status=uploading
    │   ├─ videoBuffer = Buffer.from(video.arrayBuffer())
    │   │
    │   ├─ SSE: status=analyzing_vi
    │   ├─ viResult = analyzeVideo(videoBuffer, config.language)  ← VI API (言語動的)
    │   │
    │   ├─ SSE: status=segmenting
    │   ├─ scenes = segmentIntoScenes(viResult, duration)
    │   │
    │   ├─ SSE: status=analyzing_gemini
    │   ├─ videoFileUri = uploadVideoToGemini(videoBuffer)    ← Gemini Files API
    │   ├─ transcription = transcribeWithGemini(videoFileUri, "ja")  ← 多言語文字起こし+日本語翻訳
    │   ├─ applyGeminiTranscription(scenes, transcription)   ← 原文+翻訳をシーンに分配
    │   │
    │   ├─ for each scene:
    │   │   ├─ result = analyzeSceneWithGemini(scene, ..., videoFileUri)  ← 動画付きシーン解析
    │   │   ├─ scene.geminiAnalysis = { summary, issues, overallRisk, detectedTextSummary, speechSummary }
    │   │   └─ SSE: log (進捗)
    │   │
    │   └─ SSE: type=result { scenes, issues }
    │
    └─ POST /api/import-json (FormData: jsonFile + config + duration)
        └─ (VI JSONインポート → 同じGemini解析フロー)
```
