# Video QA Review — 仕様書

## プロジェクト概要

動画をAI（Google Video Intelligence API + Gemini）で解析し、ターゲット視聴者に不適切な箇所を自動検出するWebアプリ。

### 技術スタック
- **フレームワーク**: Next.js 16 (App Router) + React 19 + TypeScript 5.9
- **スタイル**: Tailwind CSS 4 + PostCSS
- **状態管理**: Zustand 5
- **AI**: Video Intelligence API (9機能), Gemini 2.0 Flash (シーン解析), Gemini 2.5 Flash (チャンク文字起こし)
- **動画処理**: ffmpeg (チャンク切り出し, `libx264 ultrafast + aac` 再エンコード)
- **PDF**: @react-pdf/renderer

## 2つの解析パイプライン

本アプリには2つの解析パイプラインがある。

### パイプライン1: フル解析 (`/api/analyze`)
動画ファイルをVI API + Geminiでフル解析するフロー。

```
FormData: video + config + duration + mock
    │
    ├─ uploading: videoBuffer取得
    ├─ analyzing_vi: VI API 9機能で解析
    ├─ segmenting: ショット境界ベースでシーン分割
    ├─ analyzing_gemini:
    │   ├─ uploadVideoToGemini() → videoFileUri
    │   ├─ transcribeWithGemini(videoFileUri, "ja") → 全動画一括文字起こし
    │   ├─ applyGeminiTranscription(scenes, result) → シーンに分配
    │   └─ for each scene: analyzeSceneWithGemini(scene, ..., videoFileUri)
    └─ SSE: type=result { scenes, issues }
```

### パイプライン2: JSONインポート + チャンク文字起こし (`/api/import-json`)
既存のVI JSON結果をインポートし、動画があればチャンクベースで文字起こしするフロー。
**プログレッシブローディング**: VI結果を即座に返し、Gemini文字起こしは非同期でストリーミング。

```
FormData: json + video? + duration
    │
    ├─ importing_parse: JSONパース → segmentIntoScenes
    ├─ SSE: type=scenes_ready { scenes } ← フロントエンドはここで即座にシーン表示
    │
    ├─ (videoFile && GEMINI_API_KEY がある場合のみ)
    │   ├─ importing_upload: ffmpegでチャンク切り出し
    │   │   ├─ createTimeChunks(scenes, 60s) → ~60秒目標でチャンクにグループ化
    │   │   └─ splitVideoIntoChunks(videoBuffer, chunkRanges) → ffmpeg libx264 ultrafast + aac
    │   │
    │   ├─ importing_transcribe: Geminiチャンク並列文字起こし
    │   │   ├─ CONCURRENCY = 全チャンク数（全並列実行）
    │   │   ├─ for each chunk: transcribeChunkWithGemini(chunkBuffer, scenes, offset, "ja")
    │   │   │   ├─ uploadVideoToGemini(chunkBuffer) → チャンク動画をアップロード
    │   │   │   ├─ Gemini 2.5 Flash でシーン境界付き文字起こし
    │   │   │   └─ 相対タイムスタンプ → 絶対タイムスタンプ変換 (+chunkOffset)
    │   │   │
    │   │   ├─ SSE: type=transcription_scene { sceneIndex, geminiTranscription, completedScenes, totalScenes }
    │   │   │   ← シーンごとにリアルタイム送信 → フロントエンドが逐次更新
    │   │   │
    │   │   └─ レート制限対応: 429/RESOURCE_EXHAUSTED → 5秒待機 → 1回リトライ
    │   │
    │   └─ SSE: log (完了サマリ)
    │
    └─ SSE: type=result { scenes, issues }
```

## チャンクベース文字起こしアーキテクチャ

### 概要
長い動画を効率的に処理するため、動画をシーン境界に沿った~60秒チャンクに分割し、各チャンクを並列でGeminiに処理させる。

### フロー詳細

```
1. チャンク分割 (createTimeChunks)
   ├─ 入力: ChunkSceneInput[] (sceneIndex, startTime, endTime)
   ├─ シーンを順に足していき、累計が targetSeconds(60s) を超えたらそこで区切る
   ├─ シーンの途中では切らない。チャンク長はバラバラでOK
   └─ 出力: ChunkSceneInput[][] (チャンク配列)

2. ffmpeg切り出し (splitVideoIntoChunks)
   ├─ 入力: videoBuffer + ChunkRange[] (startSeconds, endSeconds)
   ├─ ffmpeg -c:v libx264 -preset ultrafast -c:a aac -avoid_negative_ts make_zero
   ├─ 再エンコード方式（-c copy はキーフレーム境界でしか切れずタイムスタンプがずれるため不採用）
   ├─ タイムアウト: 120秒/チャンク
   ├─ 一時ディレクトリに入力→出力、完了後クリーンアップ
   └─ 出力: Buffer[] (各チャンクのmp4バッファ)

3. Geminiチャンク文字起こし (transcribeChunkWithGemini)
   ├─ チャンク動画をGemini Files APIにアップロード
   ├─ シーン境界を相対時間 (0秒始まり) でプロンプトに記載
   ├─ Gemini 2.5 Flash で処理 (maxOutputTokens: 65536)
   ├─ レスポンスパース: 各シーンの words / fullTranscript / detectedLanguage / translatedTranscript / translatedWords
   ├─ タイムスタンプ変換: 相対時間 + chunkOffset → 絶対時間
   └─ 欠損シーンのフォールバック: 空配列で補完

4. 並列実行 (import-json/route.ts)
   ├─ CONCURRENCY = 全チャンク数（全並列実行）
   ├─ チャンク詳細ログ: 各チャンクの時間範囲/シーン数/サイズをSSEログ出力
   ├─ 完了したシーンごとに SSE: transcription_scene イベント送信
   └─ レート制限: 429検出 → 5秒待機 → 1回リトライ → 失敗時null
```

### Geminiモデル使い分け
| 用途 | モデル | 理由 |
|------|--------|------|
| チャンク文字起こし | `gemini-2.5-flash` | 高精度、長いJSON出力 (65536トークン) |
| シーンQA解析 | `gemini-2.0-flash` | 高速、コスト効率 |
| 全動画一括文字起こし | `gemini-2.0-flash` | analyze route用（パイプライン1） |

## SSEイベント一覧

### status イベント
フロントエンドの進捗表示を更新する。

| status値 | パイプライン | 意味 |
|-----------|------------|------|
| `uploading` | analyze | 動画ファイル読み込み中 |
| `analyzing_vi` | analyze | VI API呼び出し中 |
| `segmenting` | analyze | シーン分割中 |
| `analyzing_gemini` | analyze | Geminiシーン解析中 |
| `importing_parse` | import-json | JSONパース + シーン分割中 |
| `importing_upload` | import-json | ffmpegチャンク切り出し中 |
| `importing_transcribe` | import-json | Geminiチャンク文字起こし中 |
| `completed` | 共通 | 解析完了 |
| `failed` | 共通 | 解析失敗 |

### データイベント
| type | data | 説明 |
|------|------|------|
| `scenes_ready` | `{ scenes, issues: [] }` | VI結果のみのシーンデータ（即座に表示用） |

| `result` | `{ scenes, issues }` | 最終結果（全データ含む） |
| `error` | `{ message }` | エラー |
| `log` | `{ level, message, detail?, timestamp }` | ログエントリ |

## 音声文字起こしフロー

### パイプライン1 (analyze): 全動画一括方式
```
1. videoBuffer → uploadVideoToGemini() → videoFileUri
2. transcribeWithGemini(videoFileUri, "ja")
   ├─ Gemini 2.0 Flash
   ├─ 英語プロンプト（多言語対応）
   ├─ 自動言語検出 (detectedLanguage)
   ├─ 原文: words[] + fullTranscript
   └─ 日本語翻訳: translatedWords[] + translatedTranscript
3. applyGeminiTranscription(scenes, result) → シーンに分配
```

### パイプライン2 (import-json): チャンク並列方式
```
1. createTimeChunks(scenes, 60s) → チャンクグループ
2. splitVideoIntoChunks(videoBuffer, ranges) → ffmpeg libx264 ultrafast + aac 再エンコード
3. for each chunk (全並列):
   transcribeChunkWithGemini(chunkBuffer, scenes, offset, "ja")
   ├─ Gemini 2.5 Flash
   ├─ シーン境界付きプロンプト（相対時間）
   ├─ 各シーンの words / fullTranscript / detectedLanguage
   ├─ 日本語翻訳: translatedWords[] / translatedTranscript
   └─ タイムスタンプ: 相対→絶対変換
4. SSE: transcription_scene → フロントエンド逐次更新
```

### UI表示 (SceneDetailPanel.tsx)
```
├─ 言語バッジ: 検出言語をインジゴ色で表示 (LANG_LABELS 13言語)
├─ 翻訳ON/OFFトグル: 日本語翻訳の表示切替
├─ Gemini文字起こし中インジケータ: 紫パルスアニメーション（importing_transcribe中のみ）
├─ Gemini音声要約: 紫色カード (speechSummary)
├─ 翻訳全文: 緑色カード（翻訳ON時）
├─ ワードレベル: 原文 + インライン翻訳（文ごと）
├─ アクティブ文: 青枠 + 自動スクロール
├─ アクティブワード: 赤下線（原文）/ 緑下線（翻訳）
└─ クリック: 該当ワードの startTimeSeconds にシーク
```

## Zustandストア (useProjectStore.ts)

### プログレッシブ更新対応

```typescript
interface ProjectState {
  // --- 既存 ---
  draftVideo, draftConfig, projectName, videoFile,
  analysisStatus, scenes, issues, currentSceneIndex, filterSeverity,

  // --- チャンク文字起こし用 ---
  transcriptionProgress: { completed: number; total: number } | null;  // 文字起こし進捗

  // --- アクション ---
  setScenes(scenes)                  // scenes_ready イベントで呼ぶ
  updateScenesTranscription(updates) // transcription_scene イベントで呼ぶ（シーン単位更新）
  setTranscriptionProgress(progress) // 進捗バー更新用
}
```

`updateScenesTranscription` は `scenes` 配列内の指定インデックスのシーンだけ `geminiTranscription` を差し替える。
これにより、全シーンを再セットせずに逐次的にGemini結果を反映できる。

## 型定義（主要）

### Scene (scene.ts)
```typescript
interface Scene {
  index: number;
  startTimeSeconds: number;
  endTimeSeconds: number;
  durationSeconds: number;
  viData: {
    detectedText: DetectedText[];
    speechTranscription: SpeechWord[];
    fullTranscript: string;
    labels: SceneLabel[];
    explicitContent: { maxLikelihood: string; frames: ExplicitContentFrame[] };
    objects: TrackedObject[];
    persons: PersonDetection[];
    faces: FaceDetection[];
    logos: LogoRecognition[];
  };
  geminiTranscription?: GeminiTranscription;
  geminiAnalysis?: {
```
